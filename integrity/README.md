# Integrity Engine standard

The Integrity Engine is a public-interest data and accountability standard, not an accusation engine. Its purpose is to make relevant records easier to inspect while protecting accuracy, due process, and privacy.

## Principles

1. **Evidence before inference.** Every displayed assertion should link to an underlying lawful source or be marked as an analysis.
2. **No black-box conclusions.** Show data provenance, matching logic, confidence, and limitations.
3. **Right to correct.** Provide a documented correction and appeal process.
4. **Minimum necessary data.** Do not collect or publish personal information just because it is technically available.
5. **Human review.** Automated matches and risk flags never equal a finding of wrongdoing.
6. **Auditability.** Preserve version history, methodology, and material changes.

## Minimum source record

For each record: source URL or document identifier, source agency, publication/retrieval date, applicable jurisdiction, data field definitions, transformation steps, and uncertainty notes.

## Prohibited uses

The project must not publish unverified allegations as fact, rank people as “corrupt,” facilitate harassment, or merge datasets in a way that exposes protected personal information without a lawful public-interest basis and a reviewed privacy assessment.
