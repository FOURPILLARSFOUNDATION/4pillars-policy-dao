# Policy library

The policy library uses four stages:

| Stage | Meaning |
| --- | --- |
| `scoping` | Question framed; research plan open |
| `draft` | Proposed mechanism exists; review incomplete |
| `model` | Reviewed reusable template; jurisdictional adaptation still required |
| `retired` | Superseded or not advanced |

The source materials identify a connected economic challenge: housing pressure, automation-driven productivity, retirement financing, and public integrity. The modules below preserve that systems view while treating each intervention as independently reviewable.

| Module | Status | Scope |
| --- | --- | --- |
| [Housing capital reform](housing-capital-reform.md) | scoping | Homeowner liquidity, affordability, consumer protection |
| [Automation revenue architecture](automation-revenue-architecture.md) | scoping | Infrastructure impacts, public revenue, labor transition |
| [Retirement resilience](retirement-resilience.md) | scoping | Social Security financing and transition protection |
| [Public integrity standard](public-integrity-standard.md) | draft | Conflicts, disclosure, recusal, independent enforcement |

No module is an enacted law or a promise that a particular outcome will occur. Each must be adapted to applicable constitutional, statutory, administrative, tax, securities, consumer-protection, and campaign-finance rules.
