# Founding roadmap

## Phase 0 — Establish the Commons

- Publish the constitution, conduct rules, source standards, and proposal template.
- Recruit a cross-functional founding review circle: policy, law, data, operations, and affected-community voices.
- Select a narrow first jurisdiction and a single testable policy module.

## Phase 1 — Produce credible models

- Create an evidence dossier and public comment process for each workstream.
- Publish an implementation and fiscal assessment beside each model.
- Build a source-linked integrity prototype with correction workflow before any public scoring or ranking.

## Phase 2 — Pilot and measure

- Partner with a local organization or public body where lawful and appropriate.
- Track implementation cost, uptake, equity effects, complaints, and outcomes.
- Release a public after-action report and amend the model.

## Phase 3 — Scale responsibly

- Maintain jurisdiction-specific versions rather than claiming one model fits every state.
- Create separate, counsel-reviewed entities only when a specific regulated activity requires one.
- Keep the public repository as the durable, inspectable source of policy versions and evidence.
