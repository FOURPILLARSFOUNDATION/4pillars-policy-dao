## How to use the ecosystem

1. **Start with the pillar closest to the problem.** Read its research agenda before opening a proposal.
2. **Open one bounded issue.** State a jurisdiction, problem, mechanism, evidence, affected groups, tradeoffs, and material conflicts.
3. **Link related work.** Add a “Related repositories” section to any proposal that touches another pillar.
4. **Escalate shared decisions to the Commons.** Cross-pillar governance, standards, identity, funding, and public-position questions belong in the main repository’s decision process.
5. **Publish the result back to the pillar.** Link the decision record, model policy, pilot plan, and results where contributors started.

Read the worked [cross-repository workflow example](CROSS-REPO-WORKFLOW.md) before proposing a project that spans more than one pillar.
