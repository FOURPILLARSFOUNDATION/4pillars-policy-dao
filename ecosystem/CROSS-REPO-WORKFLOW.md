# Cross-repository workflow example

## Example: a resident-protective housing-liquidity pilot

**Question:** Could a city test a homeowner-liquidity program that reduces forced sales while preventing extractive or speculative use?

1. **Start in Housing Capital.** Open a proposal issue with the city, target group, proposed tool, source links, consumer safeguards, budget assumptions, and a measurable pilot outcome.
2. **Link Public Integrity.** If the program requires an oversight board, appraisal standards, disclosures, or conflict rules, open a linked integrity issue for those guardrails.
3. **Link Automation & Public Revenue only if needed.** If the proposal claims an automation-related revenue source, place the revenue mechanism and measurement assumptions in that repository for separate review.
4. **Return to the Commons for a shared decision.** The proposal owner creates a decision record in the main repository that links the issues, lists conflicts and unresolved questions, and states what is actually being decided.
5. **Publish a pilot packet.** The approved version links back to the Housing Capital repository with the model policy, evaluation plan, reporting cadence, sunset date, and any related integrity controls.
6. **Report results in public.** Update the original issues with implementation evidence, wins, failures, complaints, and a recommendation to continue, revise, or stop the pilot.

## Link format for proposals

Copy this into a proposal body when work crosses repositories:

```markdown
## Related repositories

- Primary workstream: [Housing Capital](https://github.com/FOURPILLARSFOUNDATION/4pillars-housing-capital/issues/NEW_ISSUE_NUMBER)
- Integrity safeguards: [Public Integrity](https://github.com/FOURPILLARSFOUNDATION/4pillars-public-integrity/issues/NEW_ISSUE_NUMBER)
- Shared decision record: [Policy Commons](https://github.com/FOURPILLARSFOUNDATION/4pillars-policy-dao/issues/NEW_ISSUE_NUMBER)

## What this repository is deciding

State the narrow question for this repository. Link out instead of duplicating research owned by another workstream.
```

## Routing rule

If a question concerns the shared governance of the Commons, compensation, public commitments made in the organization’s name, cross-pillar prioritization, or a regulated fundraising/political activity, it belongs in the main repository first. A pillar repository may research the question, but it should not unilaterally create a project-wide rule.
