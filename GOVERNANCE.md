# Governance index

The governing blueprint is in [governance/DAO-CONSTITUTION.md](governance/DAO-CONSTITUTION.md). It is designed for a public-policy collaborative, not a financial DAO:

- membership is not ownership or an investment;
- no governance token is required;
- voting power cannot be purchased;
- financial activities, political committees, and lobbying activity require separately governed, counsel-reviewed entities; and
- all material decisions should leave an accessible public record.

Any change to these core principles requires the constitutional amendment process.
